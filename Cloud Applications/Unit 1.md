# Key Characteristics of Cloud Computing 
1. On-Demand self service 
2. Broad network access 
3. Resource Planning 
4. Rapid Elasticity 
5. Measured Service 
## Examples of Cloud Based Applications 
- Gmail and Google Workspace (Docs, Sheets, Slides)
- Salesforce CRM (Customer Relation Manager)
- Dropbox and Google Drive
- Netflix and Spotify streaming platforms 
- Slack and Microsoft Teams
# Private Cloud Applications 
A private cloud is cloud infrastructure dedicated to a single organization, either hosted on premises or by a third party, but not shared with other organizations. 
## Characteristics
- Greater control over security, compliance, and data governance 
- Often used by organizations with strict regulatory requirements (banks, governments, healthcare)
- General more expensive than public cloud due to dedicated infrastructure
